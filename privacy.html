プライバシーポリシー

vlog-uploader ／ 最終更新: 2026年9月27日

対象

vlog-uploader は、所有者本人だけが自分のYouTubeチャンネルへ動画を投稿するために使う個人用ツールです。所有者以外の人の情報を扱うことはありません。

vlog-uploader is used only by its owner to upload videos to the owner's own YouTube channel. It does not handle information about anyone else.

扱う情報

  • 所有者が選んだ動画ファイルと、そのタイトル・説明文・字幕
  • YouTubeへ投稿するための認証情報（アクセストークン）

情報の使い方

上の情報は、YouTube Data API を使って所有者自身のチャンネルへ動画を投稿し、所有者自身の再生リストへ追加するためだけに使います。広告・分析・販売などには使いません。

This information is used solely to upload videos to, and manage playlists on, the owner's own YouTube channel via the YouTube Data API. It is not used for advertising, analytics or sale.

保存場所と第三者への提供

認証情報は所有者のMacの中にだけ保存し、外部のサーバーには送りません。情報を第三者へ提供・共有することはありません（動画の投稿先であるYouTube／Googleを除く）。

Credentials are stored only on the owner's Mac and are never sent to any server other than Google's. No information is shared with third parties.

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の利用と他アプリへの移転は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

削除

所有者はいつでも Googleアカウントの「サードパーティによるアクセス」 からこのツールの許可を取り消せます。取り消すとツールは投稿できなくなります。
